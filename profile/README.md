# Black Fox Group

Black Fox Group is a software company. Official website: [foxnext.net](https://foxnext.net)

The main programs are **VPS to VPN** and **BSC Wallet Recovery**. Official downloads are only on [foxnext.net](https://foxnext.net/en/download.html).

## Main programs

- **[VPS to VPN](https://foxnext.net/en/download.html)** — Windows and Android. You connect to a VPS, install the 3X-UI Sanaei panel without Linux knowledge, and build a multi-location VPN. Docs: [VPS-to-VPN](https://github.com/BlackFoxGroup/VPS-to-VPN)
- **[BSC Wallet Recovery](https://foxnext.net/en/wallet-recovery.html)** — Windows. Recover forgotten words of a 12 to 24 word phrase on BSC (BNB Smart Chain). Official page: [foxnext.net/en/wallet-recovery.html](https://foxnext.net/en/wallet-recovery.html)

## Helper tools

These extra tools help you use VPS to VPN more easily. You do not need special Linux or networking knowledge.

- **[Black Fox Config Builder](https://github.com/BlackFoxGroup/blackfox-config-builder)** — Android app to build and manage 3X-UI configs after the panel is installed. Download: [foxnext.net](https://foxnext.net/en/download.html)
- **[Telegram Bot Expert Installer](https://github.com/BlackFoxGroup/telegram-bot-expert-installer)** — install and manage a Telegram bot on a VPS from Windows, without Linux or Terminal. Download: [foxnext.net](https://foxnext.net/en/download.html)
- **[Smart Support Bot](https://github.com/BlackFoxGroup/smart-support-bot)** — open-source Telegram support bot (catalogs, channel and group help). Install it with Expert Installer if you want. Download: [foxnext.net](https://foxnext.net/en/download.html)
